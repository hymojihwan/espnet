# CHiME4 JEPA_asr1: SE + ASR (SE-JEPA)

Speech Enhancement (Conv-TasNet) + JEPA predictive + Conformer CTC on CHiME4.

## Data

- Reuses **enh1** data: **multi** (real+simu) for train/valid; test = **et05_multi** + per-SNR simu **et05_simu_snr-10, snr-5, snr0, snr5, snr10** (noisy + clean ref `spk1.scp`). Per-SNR sets require MATLAB simulation that generates `et05_*_simu_snr*` dirs.
- Run enh1 data prep first (so that multi and, if available, et05_simu_snr* exist), then JEPA_asr1 data prep.

## Usage

1. **Prepare enh1 data** (if not done):
   ```bash
   cd egs2/chime4/enh1
   # set extra_annotations in run.sh or pass to data.sh
   local/data.sh --extra-annotations /path/to/CHiME4/annotations --stage 1 --stop-stage 2
   ```

2. **Prepare JEPA_asr1 data** (symlink from enh1 + nlsyms):
   ```bash
   cd egs2/chime4/JEPA_asr1
   local/data.sh
   ```

3. **Train & decode SE-JEPA ASR**:
   ```bash
   ./run_se_jepa.sh
   ```

## Config

- `conf/tuning/train_se_jepa_scratch.yaml`: SE-JEPA model (Conv-TasNet + JEPA + Conformer CTC).
- `conf/tuning/decode_jepa_ctc.yaml`: CTC decoding.

Adjust `--ngpu`, `--nj`, `--inference_nj` in `run_se_jepa.sh` as needed.

If per-SNR et05 sets (`et05_simu_snr*`) were not generated by the MATLAB simulation, edit `run_se_jepa.sh` and set `test_sets="et05_multi_isolated_1ch_track"` only.
